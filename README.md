# Anitya Labs theme

Shopify theme for anityalabs.com. Dawn underneath, one custom section (`sections/anitya-home.liquid`) for the home page, email capture through Shopify's customer form (`snippets/anitya-signup.liquid`, tags `app-list` and `product-waitlist`).

Pipeline: this repo is connected to the store through Shopify's GitHub integration. Push to `main` and the theme updates within a minute. Copy and images are also editable in Shopify's theme editor; edits made there are committed back to this repo by Shopify.

Palette and type follow the Anitya app: background #15140f, ink #efe9dc, amber #d9a86c, Fraunces for words, Inter for numbers.
